# Karra Jadval Sarguzashti

7-8 yoshli bolalar uchun karra jadvalni o'rgatuvchi Android o'yin.

- **O'rganamiz** — har bir jadval uchun alohida usul (mashina, zinapoya, shokolad, soat, hiyla, kalendar, ikkilantirish, barmoq)
- **Mashq qilamiz** — Alohida / Barchasi
- **Musobaqa** — vaqt bilan
- **Chempionat** — 12 bosqich, vaqt 14 soniyadan 5 soniyagacha kamayadi, javobni o'zi yozadi
- **Reyting** — onlayn (ota-ona ruxsati bilan) va shu telefon bo'yicha
- **Tahlil** (yuqori o'ngdagi 📊) — ota-onalar uchun hisobot
- **Dam olish** — 20 daqiqa o'yindan so'ng 10 daqiqa tanaffus (ko'zlar uchun)

Onlayn reytingni ulash: [ONLINE_SETUP.md](ONLINE_SETUP.md).
