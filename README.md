# Karra Jadval Sarguzashti

7-8 yoshli bolalar uchun karra jadvalni o'rgatuvchi Android o'yin.

- **O'rganamiz** — qurbaqa sakrashi bilan o'rganish va sinov
- **Mashq qilamiz** — Alohida / Barchasi rejimlari
- **Musobaqa** — vaqt bilan, reyting
- **Tahlil** — ota-onalar uchun hisobot

## APK olish
GitHub'da **Actions** → "APK yig'ish" → oxirgi ishga tushirish → **Artifacts** → `KarraJadval-apk`.
Yoki **Releases** bo'limidan `KarraJadval.apk` ni yuklab oling.
