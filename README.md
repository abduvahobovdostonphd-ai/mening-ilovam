# Karra Jadval Sarguzashti

7-8 yoshli bolalar uchun karra jadvalni o'rgatuvchi Android o'yin.

- **O'rganamiz** — har bir jadval uchun alohida usul (mashina, zinapoya, shokolad, soat, hiyla, kalendar, ikkilantirish, barmoq)
- **Mashq qilamiz** — Alohida / Barchasi, tugma yoki ovoz bilan javob
- **Musobaqa** — vaqt bilan, reyting
- **Chempionat** — 4 bosqichli, javobni o'zi yozadi yoki ovoz bilan aytadi
- **Tahlil** (yuqori o'ngdagi 📊) — ota-onalar uchun hisobot
- **Dam olish** — 20 daqiqa o'yindan so'ng 10 daqiqa majburiy tanaffus (ko'zlar uchun)

## APK olish
GitHub'da **Releases** bo'limidan `KarraJadval.apk` ni yuklab oling
yoki **Actions** → oxirgi ishga tushirish → **Artifacts**.
